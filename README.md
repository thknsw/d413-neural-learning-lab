# D413 Audio Learning Lab — Neural Narration Edition

This is the upgraded version of your existing D413 Audio Learning Lab. **The Safari/system speech voice has been removed.** The app now plays **real MP3 lessons** generated from your existing 60 lecture scripts using the open-source [`edge-tts`](https://github.com/rany2/edge-tts) project and Microsoft Edge's online neural voices.

## What is included

- All 60 original lessons, the same three-question mini-quizzes, 12 section quizzes, and five 50-question practice exams
- Three neural narrators: **Jenny** (US female), **Andrew** (US male), and **Sonia** (UK female)
- Native HTML audio playback designed for iPhone Safari, including Play/Pause, seeking, 15-second skips, playback speeds from 0.8× to 2×, voice selection, and resume points
- A GitHub Actions workflow that generates the 180 MP3 files and hosts the completed learning app using GitHub Pages
- Progress saved in each browser's local storage

**Important:** The ZIP does *not* include premade MP3s. Natural voice files must first be generated by the workflow. Until that step completes, quizzes and transcripts work, but pressing Play will report that the MP3s are missing. This is intentional: no robotic-device-voice fallback.

## Publish and automatically generate all narration through GitHub

1. Create a new GitHub repository, e.g. `d413-neural-learning-lab`, preferably **public** if you want free GitHub Pages hosting. (Public Pages websites are viewable to anyone with the URL.)
2. Unzip the project package and upload/push **its contents**, retaining the `.github/workflows/build-neural-audio.yml` file, to the repository's **main** branch. Do not upload only the ZIP.
3. In GitHub repository **Settings → Pages**, set **Build and deployment → Source: GitHub Actions**.
4. Open the **Actions** tab. The “Build neural audio and deploy” workflow should run automatically on the push. If it hasn't started, select the workflow → **Run workflow**.
5. When both *build* and *deploy* complete, open the website URL from the workflow's deployment or Settings → Pages. This is your narrated app. On iPhone, open it in Safari and optionally use **Share → Add to Home Screen**.
6. Optional: Under the completed GitHub Actions run, download **D413-Neural-Audio-Lab-Offline**. It contains the HTML and real MP3 files. Host the extracted files together on any ordinary web server if you don't want to use GitHub Pages.

The voice generator connects to Microsoft's online service using `edge-tts`. It does not require a paid key, but it is an **unofficial service integration** that may change or throttle connections. The workflow fails visibly rather than claiming to generate audio when it cannot. GitHub Actions and GitHub Pages limits may apply.

### If you have a terminal and prefer local generation

```bash
python -m pip install -r requirements.txt
python scripts/generate_audio.py --dry-run
python scripts/generate_audio.py --concurrency 2
python -m http.server 8000
```

Then visit `http://localhost:8000` on your computer. All audio is placed in `audio/jenny/`, `audio/andrew/`, and `audio/sonia/` next to `index.html`. A local connection to the voice service is required to **generate** the audio; playback of downloaded MP3s does not need that connection.

To regenerate only one voice: `python scripts/generate_audio.py --voice jenny --overwrite`.

## Notes

- **No account is required in the app itself.** Your learning progress is stored in the browser on that device. Changing browsers, clearing website data, or switching website origins will not move that progress automatically; use the app's Export Progress feature to keep a backup.
- **iPhone lock-screen audio:** Native MP3 playback is more compatible with lock-screen/Control Center controls than JavaScript text-to-speech, but exact behavior still depends on Safari/iOS settings. Test on your device.
- **Not WGU material.** This is independently written exam preparation, not an official WGU exam bank.
- **Voice provider:** Original voices may have service-specific usage terms. Check current terms if distributing beyond personal study.
